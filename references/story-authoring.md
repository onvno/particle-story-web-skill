# 制作参考

## 起一个独立故事

从工作区内运行，选择还未存在的项目路径。把 `<skill-dir>` 换成包含此 Skill 的实际绝对路径。

```sh
node <skill-dir>/scripts/scaffold.mjs ./change-moon
```

进新项目后，把故事 JSON 写到 `stories/`，把 WebP 放到 `dist/art/`。独立故事用空字符串作为 `slug`，这样它会生成站点首页。如需先看捆绑的盘古示例，可在初始化时加 `--example`。添加到已有选集时，创建独立英文 `slug`，文件名排序决定选集顺序，空 `slug` 只留给首页。

## 故事配置

```json
{
  "slug": "",
  "title": "嫦娥奔月",
  "seal": "月",
  "theme": "sky",
  "description": "从人间飞向明月的粒子叙事。",
  "finale": "custom",
  "endingLayers": [
    {"region": [0.68, 0.26, 0.15, 0.16], "move": [0.00, 0.00], "speed": 0.65, "pulse": 0.3},
    {"region": [0.50, 0.54, 0.38, 0.23], "move": [0.04, -0.012], "speed": 0.52, "pulse": 0.12}
  ],
  "chapters": [
    {
      "id": "earth",
      "art": "change-earth",
      "label": "人间月夜",
      "short": "人间",
      "title": ["嫦娥", "奔月"],
      "text": ["在那个传说里，嫦娥来到离人间很远的地方。"],
      "pigment": "original"
    },
    {
      "id": "moon",
      "art": "change-moon",
      "label": "月宫寂静",
      "short": "月宫",
      "title": ["月上", "长夜"],
      "text": ["尘光缓缓飘过，远处的月轮泛起柔光。"],
      "pigment": "original"
    }
  ]
}
```

这是演示配置格式的两幕片段。正式故事按情节展开完整的起承转合。各幕使用独立的短锚点和素材名，`art` 省略文件扩展名。标题分两行，正文数组中每项占一行。主题预设为 `earth` 铜金、`sky` 青玉和 `sea` 靛蓝。配色可选 `bronze`、`celadon` 或 `original`。用 `force` 控制进入该幕前的散开力度，省略时为 0.96。宽景可以用 `height: 0.86` 和 `feather: 0.15` 增加呼吸空间。

图像常用 600–960 像素方形 WebP。采样由亮度驱动，重点部位要与暗部有清楚的亮度差。连续的人物保持辨识度，轮廓尽量不贴四边。把画面中活起来的位置先标出来，再匹配终幕参数。生成图出现偏离情节的细节时，先修正实际素材。

## 终幕动效

- `river` 适合下半幅有弯曲河面的山水，上半幅的雾带也会移动。模板中的路径按示例山河中的河弯绘制。
- `clouds` 适合上半幅有云带或彩色天光的画面。
- `tide` 适合下半幅是成层海浪的画面。
- `custom` 使用 1–3 个 `endingLayers`。每层的 `region` 是椭圆中心横纵坐标加横纵半径，都基于原图 0–1 坐标，左上角为原点。`move` 是横、纵位移的最大幅度，负数改变方向。`speed` 用弧度每秒，`pulse` 是亮度起伏比例。比如对准月轮的一层可以把位移设为零，给月轮做呼吸光。另一层对准浮尘，只用微小位移和缓慢的亮度变化。
- `still` 让最后一幕停驻，适合用户明确要静止结尾的情况。

先用预设或少量自定义区域做出贴合故事的效果。火焰上升、鸟群绕行等特定行为需要独立轨迹时，可以扩展终幕着色器。只把时间依赖放到 `uEnding > 0` 的分支，保留章节变形只读取滚动进度的约定。旧版选集没有 `custom` 时，把模板中的配置校验、HTML 数据和着色器支持一起合并，核查现有故事。

## 构建与回归

在故事项目里运行：

```sh
node scripts/build-stories.mjs
node scripts/test-stories.mjs
python3 -m http.server 8741 --bind 127.0.0.1 --directory dist
```

自动化检查覆盖生成文件、可逆滚动、章节接续和终幕动效。加载测试会延迟最后一张图，验证首帧画出后才揭开加载层，并检查切回标签页时保持粒子画面，以及素材错误、WebGL 不可用或减少动态效果时的静态阅读。实际预览时可用慢速网络刷新首屏，用鼠标或触屏往返两幕，再在末幕停留几秒。正式构建产物是 `dist/`，浏览端无构建及第三方运行时依赖。
